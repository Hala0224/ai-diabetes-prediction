# Diabetes Prediction — Intelligent System

Final project for the **Artificial Intelligence – Intelligent Systems** course (2024/2025).

Develops an intelligent system that predicts whether a patient has diabetes from medical and demographic data, and compares tools and approaches (bottom-up and top-down) for building intelligent systems.

## Contents

| File | Description |
|------|-------------|
| [AI-Final-Report.pdf](AI-Final-Report.pdf) | Final report: AI tools & techniques comparison, system design, evaluation |
| [AI-Presentation.pptx](AI-Presentation.pptx) | Presentation on the fundamentals of AI |
| [Diabetes_Prediction.ipynb](Diabetes_Prediction.ipynb) | Data exploration, preprocessing, Logistic Regression model, MLflow tracking |

## Dataset

[Diabetes Prediction Dataset](https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset) on Kaggle — download `diabetes_prediction_dataset.csv` and place it next to the notebook.

## Results

Logistic Regression reached **96 % accuracy** on the test set.
